# Displacement inputs for the renders

Generated by `pipeline/make_render_inputs.py` from the six-way structure set. Every number
here comes from one place so the figures and the analysis can never disagree; don't
recompute displacement in PyMOL.

## `displacement_<protein>_<variant>.csv`

`object,resid_uniprot,displacement_A` — how far each residue of that structure moved from
**its own** wild type (`exp_mut` vs `exp_wt`, `af_mut` vs `af_wt`, `esm_mut` vs `esm_wt`),
after C-alpha superposition. UniProt numbering, matching the PDB files you were given.

| case | exp_mut | af_mut | esm_mut | largest displacement (A) |
|---|---|---|---|---|
| `pdz3_rat_G330T` | 101 | 101 | 101 | 3.33 |
| `pdz3_rat_H372A` | 101 | 101 | 101 | 2.45 |
| `ubq_human_K11S` | 75 | 76 | 76 | 3.97 |
| `ubq_human_K33S` | 76 | 76 | 76 | 5.30 |
| `ubq_human_L67S` | 75 | 76 | 76 | 6.16 |

`exp_mut` has 75 rows for K11S and L67S because chain A of 4PIG and 5OXI stops at residue
75. Residue 76 is absent, not still — paint anything missing grey (`b = -1`), never white.

## `noise_floor.csv`

`figure_scale_min_A` is the `minimum` for the colour scale, and it is **one value per
protein**, deliberately the same across all three panels of a figure. It is the largest
floor among the predictors on that figure, so nothing below any predictor's own noise
can read as signal. `floor_A` is each predictor's own floor, for reference.

`scored_on = core_1_71` for ubiquitin: residues 72-76 are a flexible tail that both
predictors swing about 1 A regardless of sequence. They are in the displacement CSVs with
their true values, but they are not structure — grey them out like a missing residue and
say so in the caption. PDZ3 has no such region and is scored whole-chain.

## What is final and what will move

- `exp_mut` — final. Crystal structures don't change.
- `esm_mut` — final. ESMFold is deterministic and already ran at production settings.
- `af_mut` — **provisional.** These AF2 structures are from the development subset
  (`subset_v0`, one model, shallow MSA). The production run is on the cluster; when it
  lands, the `af_mut` rows and the AlphaFold2 floors are regenerated and the AF2 panels
  need redrawing. Everything else stands.

Build and check the whole pipeline now on these files — only the AF2 panel changes later.
